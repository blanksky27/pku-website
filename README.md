# Understanding PKU — Website

A simple, responsive educational website about phenylketonuria (PKU), based on the supplied school presentation.

## Files

- `index.html` — the complete website (HTML, CSS and JavaScript in one file).

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No packages, build tools or external libraries are required.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.
